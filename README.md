# PRODIGY_WD_05
Weather Web Application:

This project is a responsive Weather Web Application developed using HTML, CSS, and JavaScript. It fetches real-time weather data from a weather API based on the user’s current location or a city entered by the user. The application displays essential weather details in a clean, interactive, and mobile-friendly interface.

Features:

• Search weather by city name
• Fetch real-time weather data using API
• Display temperature, humidity, and wind speed
• Show weather condition icons
• Location-based weather detection
• Error handling for invalid city names
• Fully responsive design for all screen sizes
• Built using pure HTML, CSS, and JavaScript

Technologies Used:

• HTML5
• CSS3
• JavaScript
• Weather API (OpenWeatherMap or similar)

Project Objective:

The objective of this project is to build a dynamic web application that integrates third-party APIs to display real-time data while improving JavaScript and front-end development skills.

How It Works:

The user enters a city name or allows location access.
JavaScript sends a request to a weather API.
The API returns real-time weather data in JSON format.
The application extracts and displays relevant weather details.
The interface updates dynamically whenever a new search is made.

Learning Outcomes:

• Working with APIs and JSON data
• Using Fetch API and asynchronous JavaScript
• Handling user input and errors
• Building real-time dynamic web applications
• Designing responsive and user-friendly interfaces
